# CLI Miner v1 (interactive + distribution) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `dinero-sv2-miner` (and the GPU twin) the idiot-proof "paste an address, press Enter" miner, installable with one terminal command on macOS/Windows/Linux/Chromebook.

**Architecture:** A new shared crate `dinero-miner-ux` holds the four pure units (address validation/P2TR conversion, config with flag>config>default precedence, interactive prompt state machine, human display renderer). Both miner binaries consume it; `--json` and non-TTY output stay byte-identical (the DineroMiner GUI and its fixtures depend on them).

**Tech Stack:** Rust (existing workspace: clap, tokio, serde/serde_json, anyhow, hex). New workspace deps: `bech32 = "0.11"`, `dirs = "5"`. Spec: `docs/superpowers/specs/2026-08-14-cli-miner-ux-design.md`.

## Global Constraints

- Repo `~/src/dinero-sv2`, branch `feat/cli-miner-ux` off `main`. Commit after every task.
- Built-in defaults (spec, verbatim): pool `173.249.200.59:4444`, server pubkey `3c879d90c9bb430493dfbf02cecbb93c3ae0d9d6c31d0757595e353fbe927417`, reward_mode `shared`, threads = logical cores − 1 (min 1).
- Precedence everywhere: CLI flag > config file (`~/.config/dinero-miner/config.json` via `dirs::config_dir()`) > built-in default.
- `--json` mode and non-TTY human output must remain BYTE-IDENTICAL to today. Golden test enforces it (Task 6).
- Never prompt when stdin is not a TTY — fail fast with a clear message.
- **Documented behavior change:** unspecified reward mode becomes `shared` (was clap-default `solo`). Callout goes in the release notes (Task 10) and README (Task 9).
- The binary FILE name stays `dinero-sv2-miner` (DineroMiner's sidecars.lock keys on it); installers install the COMMAND as `dinero-miner`.

### Task 4: `prompt` module — interactive address entry

**Files:**
- Create: `crates/dinero-miner-ux/src/prompt.rs`
- Modify: lib.rs (add `pub mod prompt;`)

**Interfaces:**
- Produces:

```rust
pub enum PromptOutcome { Address(String), Aborted }
/// Reads lines from `input`, writes prompts/errors to `out`. `saved`: offer
/// Enter-to-reuse. At most 3 invalid attempts, then Aborted. Pure I/O-trait
/// function — main() passes real stdin/stderr, tests pass cursors.
pub fn prompt_for_address(
    input: &mut dyn std::io::BufRead,
    out: &mut dyn std::io::Write,
    saved: Option<&str>,
) -> PromptOutcome;
```

Behavior (assert exact strings in tests):
- No `saved`: prompt `paste your Dinero address (din1p…): `
- With `saved`: prompt `mine to <saved>? [Enter = yes / paste a new address]: `; empty line → reuse saved.
- Invalid input: print `  ✗ <AddressError::message()>` then re-prompt; 3 strikes → Aborted.
- Valid: echo `  ✓ valid — saved for next time` and return normalized address (via `address::validate_address`).

```bash
# DINERO_MINER_VERSION=miner-vX.Y.Z overrides "latest".
set -eu
REPO="DineroLabs/dinero-sv2"
case "$(uname -s)-$(uname -m)" in
  Darwin-arm64)  T="aarch64-apple-darwin" ;;
  Linux-x86_64)  T="x86_64-unknown-linux-gnu" ;;
  Linux-aarch64) T="aarch64-unknown-linux-gnu" ;;
  *) echo "unsupported platform: $(uname -s)-$(uname -m)"; exit 1 ;;
esac
TAG="${DINERO_MINER_VERSION:-$(curl -fsSL https://api.github.com/repos/$REPO/releases | \
  grep -o '"tag_name": *"miner-v[^"]*"' | head -1 | cut -d'"' -f4)}"
[ -n "$TAG" ] || { echo "no miner release found"; exit 1; }
BASE="https://github.com/$REPO/releases/download/$TAG"
TMP=$(mktemp -d); trap 'rm -rf "$TMP"' EXIT
curl -fsSL -o "$TMP/miner" "$BASE/dinero-sv2-miner-$T"
curl -fsSL -o "$TMP/SHA256SUMS" "$BASE/SHA256SUMS"
( cd "$TMP" && grep "dinero-sv2-miner-$T\$" SHA256SUMS | sed "s|dinero-sv2-miner-$T|miner|" | \
  { shasum -a 256 -c - 2>/dev/null || sha256sum -c -; } ) || { echo "checksum mismatch"; exit 1; }
mkdir -p "$HOME/.local/bin"
install -m 755 "$TMP/miner" "$HOME/.local/bin/dinero-miner"
echo "installed: $HOME/.local/bin/dinero-miner ($TAG)"
case ":$PATH:" in *":$HOME/.local/bin:"*) ;; *) echo 'add to PATH: export PATH="$HOME/.local/bin:$PATH"' ;; esac
echo "run: dinero-miner"
```
